CHARACTER CREATION RULES (Stage S33)

The following rules are implemented as typed schema: 1 objects in the `rules` collection of dnd-core.json to support 1st-level character building and derived stat calculation.

1. Ability Score Generation (ability-score-generation)
- Standard Point Buy (DMG, default 28 pts; base 8, range 8–18): 8=0, 9=1, 10=2, 11=3, 12=4, 13=5, 14=6, 15=8, 16=10, 17=13, 18=16.
- Elite Array: 15, 14, 13, 12, 10, 8.
- Standard Roll: 4d6 drop lowest (6 times).
- Modifier = floor((Score - 10) / 2). Playable characters have a minimum Intelligence of 3 after racial adjustments.

2. Character Advancement (character-advancement)
- XP required for level L = L × (L - 1) × 500.
- Max class skill ranks = level + 3 (4 at level 1). Max cross-class skill ranks = (level + 3) / 2 (2.0 at level 1).
- General feats gained at levels: 1, 3, 6, 9, 12, 15, 18.
- +1 Ability score increases at levels: 4, 8, 12, 16, 20.

3. Hit Points (hit-points)
- Level 1 HP = max(1, class Hit Die + Con modifier) + flat bonuses (e.g., Toughness +3).

4. Skill Points & Starting Languages (skill-points-and-ranks)
- Level 1 Skill Points = max(1, class base + Int modifier) × 4 (+4 for Humans).
- Class skill = 1 pt/rank; cross-class skill = 2 pts/rank.
- Starting bonus languages = max(0, Int modifier) chosen from race bonus languages.

8. Derived Combat Statistics (derived-combat-stats) & Level-1 Class Choices (level-1-class-choices)
- AC = 10 + armor + shield + min(Dex mod, maxDex) + size + natural + dodge + deflection + misc.
- Touch AC excludes armor, shield, and natural armor; Flat-Footed AC excludes positive Dex and dodge bonuses.
- Initiative = Dex mod + misc; Melee = BAB + Str (or Dex w/ Weapon Finesse) + size + mods; Ranged = BAB + Dex + size + mods; Grapple = BAB + Str + grapple size mod.

MULTICLASSING RULES (Stage S34 — see MULTICLASSING.txt)

Implemented as 4 typed schema: 1 rules in dnd-core.json `rules[]`:
- `multiclassing-progression`: ordered level-sequence aggregation (character level vs. class level, summed HP/BAB/saves, iterative attacks at +6/+11/+16, union-of-class-skills max ranks with per-level spend costs, character-level feats & ability increases, separate class spellcasting + prestige advancement, Barbarian illiteracy exception).
- `multiclass-feature-stacking`: Turn/Rebuke Undead (cleric + paladin - 3), Uncanny Dodge -> Improved Uncanny Dodge & flanking stack (barbarian/rogue/assassin/dwarven-defender/shadowdancer + Fate domain), Sorcerer + Wizard familiar stacking, Sneak Attack dice stacking, Trap Sense bonus stacking, non-stacking Evasion.
- `monk-continuous-levels`: contiguous-block continuity constraint from MONK.txt (no returning to Monk after raising another class).
- `multiclass-xp-penalty`: optional PHB p. 60 / RACES.txt favored-class XP penalty (–20% per non-exempt base class ≥ 2 levels behind highest non-exempt base class; prestige classes exempt).
